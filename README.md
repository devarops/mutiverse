# mutiverse

Language-agnostic mutation testing. Find gaps in your test suite automatically.

## What it does

Mutation testing measures test quality by introducing small changes (mutations) into your source code and checking whether your tests catch them. If a test fails after a mutation, the mutant is killed. If tests still pass, the mutant survived — revealing a gap in your test coverage.

Mutiverse is the core engine that applies mutations, runs your test suite, and reports which mutants survived.

## How to use it

1. Provide a mutation plan — a JSON file listing the code changes to try. Plans are generated by language-specific plug-ins (Tree-sitter based) that analyze your source code and identify valid mutation points.
2. Call `apply_mutations_from_plan` with the plan path and your test command. The engine applies each mutation, runs your tests, and prints the outcome.
3. An optional JSON report records which mutations survived, helping you focus on untested code paths.

## Before you start

- Docker (recommended) or Lua 5.1 with luarocks
- Python 3 with the `jsonschema` package (for plan validation)
- busted (test runner, required for development)

## Run the project

```bash
docker compose up -d
docker exec mutiverse_ci make tests
```
